# Student GPA Calculator

This is a simple GPA calculator website I built using HTML, CSS, and JavaScript.  
It helps users calculate their GPA by adding courses, selecting grades, and entering credit hours.

🌐 Live site: https://yoseph-ad.github.io/gpa-calculator/

---

## What it does

- You enter a course name  
- Choose a grade (A, B, C, D, F)  
- Enter credit hours  
- Click "Add Course"  
- It calculates your GPA automatically
